# Security

Please report these in private, through **Security > Report a vulnerability** on GitHub:

- A repository that makes `beforeopen` execute something, write outside its temporary folder, or send data.
- A way to control the terminal, the GitHub summary or the runner through the output.

Please open a public issue for these, since there is no one to protect by waiting:

- An execution point that is not detected.
- A false positive.

Only the latest version receives fixes.
